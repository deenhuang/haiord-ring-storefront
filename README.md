# HAIORD Ring / 元序智能戒指

Bilingual product storefront and Shopify Online Store 2.0 theme for HAIORD Ring.

## Contents

- `storefront/`: standalone React + Vite frontend. Run `npm ci` and `npm run dev` from this directory.
- `shopify/builder/`: source for the Shopify home-page frontend. Run `npm ci` and `npx vite build --config vite.config.mjs` here to rebuild its bundled assets.
- `shopify/theme/`: Shopify theme source. Import the ZIP below, or work on these files directly.
- `HAIORD-Ring-Shopify-theme.zip`: ready-to-import theme package.

The reservation experience is a frontend preview. It does not collect deposits, create orders, or transmit customer data. Configure Shopify products, Markets, policies, and checkout before publishing a live store. Product media was retained from the supplied materials and should be reviewed for embedded legacy branding and publication rights.
